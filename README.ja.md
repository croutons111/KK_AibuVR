# KK_AibuVR

[English](README.md) | **日本語**

> **Koikatsu VR** の H シーンで、ハンド愛撫アイテムをその場で切り替え、胸愛撫中も乳首が自然に立った状態を保つ BepInEx プラグインです。

---

## 概要

VR の H シーンでは、ハンド愛撫のアイテムがゾーンごとに固定されています。KK_AibuVR は次の2つを追加します。

- **ハンドアイテム切り替え** — VR コントローラーのボタンまたはキーボードで、左右それぞれのアイテムをリアルタイムに切り替え。
- **乳首立ち補正** — 指愛撫中に乳首が胸へ埋まるのを防ぎます。

> **β 版** — HF Patch 3.36 ＋ Meta Quest 2（Oculus Link / Air Link）で動作確認済み。

---

## 動作環境

| 項目 | 要件 |
|---|---|
| ゲーム | Koikatsu（HF Patch 3.36）— **`KoikatuVR.exe` のみ**（VR ビルド） |
| フレームワーク | BepInEx 5.4.x |
| VR ヘッドセット | Meta Quest 2（他ヘッドセットは未確認） |

BepInEx 以外の依存はありません。非 VR ビルドでは何もしません。

---

## 導入方法

1. [Releases](../../releases) から最新の `KK_AibuVR.dll` をダウンロード。
2. `BepInEx/plugins/` フォルダに配置。
3. `KoikatuVR.exe` を起動。

---

## 使い方

VR の H シーン（愛撫／挿入／手／口の各モード）で動作します。

### アイテム切り替え

- 設定した**コントローラーボタン**または**キーボードキー**を押すと、愛撫アイテムが切り替わります。
- **左右の手は独立して切り替え**られます（各コントローラーに別ボタン）。
- 現在の愛撫ゾーンで使えないアイテムは**自動でスキップ**されます。

**アイテムとゾーンの対応:**

| アイテム | 胸 | 股間・アナル | 尻 |
|---|---|---|---|
| もみ | ✔ | ✔ | ✔ |
| なでる系 | ✔ | ✔ | ✖（ボディにめり込むためスキップ） |
| 電マ | ✔ | ✔ | ✔ |
| バイブ | ✔（胸のみ） | ✖ | ✖ |

> バイブは胸以外のゾーンでは表示されません（ゲーム仕様）。

### 乳首立ち補正

- 胸への指愛撫を検出すると自動で補正を開始し、離れると自動で解除します。
- 補正量は設定で調整できます（設定を参照）。デフォルトは補正なし。

## 設定

ゲーム内 **BepInEx Configuration Manager**（デフォルト: `F1`）から変更できます。

### Hand Caress（ハンド愛撫）

| 設定項目 | デフォルト | 説明 |
|---|---|---|
| Enabled | `true` | 機能全体の有効/無効。`false` でアイテム切り替えと乳首補正が両方無効になります（バニラ動作）。 |
| Nipple Protrusion | `1.0` | 胸愛撫中の乳首突出量。`1.0` = 補正なし、`3.0` = 推奨（約6mm）、`8.0` = 最大（約20mm）。 |

### Controls（操作）

| 設定項目 | デフォルト | 説明 |
|---|---|---|
| Cycle Key (Keyboard) | `Tab` | **両手同時**にアイテムを切り替えるキーボードキー。 |
| Cycle Button - Left Controller | `Grip` | **左手**のアイテムを切り替えるボタン。 |
| Cycle Button - Right Controller | `Grip` | **右手**のアイテムを切り替えるボタン。 |

**ボタンの選択肢:** `None`（無効）/ `Grip` / `Menu` / `Touchpad` / `Touchpad_Up` / `Touchpad_Down` / `Touchpad_Left` / `Touchpad_Right`

コントローラーを `None` にすると、その手の切り替えのみ無効になります（もう一方の手には影響しません）。
